# CueGrid Pro 🎧
### Автоматическая расстановка Hot Cues и Memory Cues для Pioneer Rekordbox

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.110+-009688.svg)](https://fastapi.tiangolo.com)
[![Rekordbox](https://img.shields.io/badge/Rekordbox-5%20%7C%206%20%7C%207-black.svg)](https://rekordbox.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Platform Windows](https://img.shields.io/badge/platform-Windows-blue.svg)](https://microsoft.com)

**CueGrid Pro** — мощное и простое десктопное приложение для диджеев, позволяющее автоматически анализировать музыкальные треки, определять темп (BPM), сетку тактов (Beatgrid), находить первый сильный бит (Downbeat) и расставлять точки **Hot Cues** (A-H) и **Memory Cues** по заданной тактовой сетке (каждые 8, 16, 32, 64 бара) с экспортом в **Pioneer Rekordbox XML**.

---

## ✨ Ключевые возможности

- 🚀 **Drag & Drop**: быстрое добавление отдельных файлов, списков треков или целых музыкальных папок (MP3, WAV, FLAC, AIFF, M4A, OGG).
- 🎵 **Точный DSP-анализ**:
  - Быстрое и прецизионное определение темпа трека (BPM) и фазы сетки на базе `Librosa` и `SciPy`.
  - Алгоритм **Back-propagation** для треков с эмбиентным/инструментальным вступлением без ударных (протягивает идеальную сетку назад к началу трека).
  - Поддержка настройки диапазона BPM (например, 60–180, 50–90 для halftime/drum&bass, 140–200).
- 🎛️ **Двойная система меток**:
  - **Hot Cues (A–H)**: кнопки быстрого запуска на контроллерах и плеерах с фирменной цветовой гаммой Pioneer DJ.
  - **Memory Cues**: метки памяти для точного обратного отсчета тактов на экранах Pioneer CDJ/XDJ (с защитой от превышения лимита до 8 меток).
  - Возможность выбора: *Только Hot Cues*, *Только Memory Cues* или *Оба типа одновременно*.
  - Гибкие шаблоны названий меток (`16 Bars`, `32 Bars` / `Bar 1`, `Bar 17`, `Bar 33` / `Intro, Drop, Break`).
- 🌊 **Интерактивная вейвформа (Waveform)**:
  - Визуализация формы волны и цветных меток в реальном времени.
  - Встроенный аудиопроигрыватель для моментальной проверки попадания точки в бит.
  - Кнопки точной подстройки сетки: сдвиг на `±10 мс`, `±50 мс` и коррекция темпа в 2 клика.
- 🔒 **100% приватность и безопасность**:
  - Вся обработка происходит **локально на вашем компьютере**.
  - Программа не отправляет аудиоданные в облако и не требует внешних API-ключей.
- 📥 **Совместимость**:
  - Генерация стандартного файла `rekordbox.xml`, совместимого со всеми версиями Rekordbox (5, 6, 7).

## 🚀 Установка и запуск

### Вариант 1: Быстрый запуск из исходного кода

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/Shurui-1/cue.grid.pro.git
   cd cue.grid.pro
   ```

2. **Создайте и активируйте виртуальное окружение** (рекомендуется):
   ```bash
   python -m venv CueGridPro/.venv
   CueGridPro\.venv\Scripts\activate
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r CueGridPro/requirements.txt
   ```

4. **Запустите программу**:
   - Дважды кликните по `CueGridPro/start.bat` (или выполните команду `python CueGridPro/start.py`).
   - Или запустите `CueGridPro/setup_shortcut.bat`, чтобы создать удобный ярлык `CueGrid Pro.lnk` в основной папке.

## 📖 Как импортировать результат в Pioneer Rekordbox

1. В программе перетащите треки, выберите нужный интервал баров и нажмите **«Экспорт в rekordbox.xml»**.
2. Откройте **Rekordbox**:
   - Перейдите в меню: **Настройки** (*Preferences* / значок шестеренки) &rarr; вкладка **«Дополнительно»** (*Advanced*) &rarr; вкладка **«База данных»** (*Database*).
   - В поле **rekordbox xml** нажмите **«Обзор»** (*Browse*) и выберите сохраненный файл `rekordbox_auto_cues.xml`.
3. В левой боковой панели Rekordbox раскройте пункт **rekordbox xml**:
   - Раскройте плейлисты, найдите **«Auto Cues»** (или выделите нужные треки).
   - Нажмите правой кнопкой мыши &rarr; **«Импортировать в коллекцию»** (*Import to Collection*).
4. **Готово!** Ваши треки в коллекции Rekordbox мгновенно получат расставленные Hot Cues и Memory Cues с идеальной тактовой сеткой.
