# Rekordbox Auto Cue Generator (CueGrid Pro) 🎧

Простая и удобная программа с современным диджейским интерфейсом для автоматического анализа треков, расстановки точек (Hot Cues и Memory Cues) по заданной тактовой сетке (каждые 8, 16, 32, 64 бара) и экспорта в **Pioneer Rekordbox**.

---

## ✨ Возможности

- 🚀 **Drag & Drop**: просто перетащите один трек, пачку файлов или целую папку с музыкой (MP3, WAV, FLAC, AIFF, M4A, OGG).
- 🎵 **Автоматический анализ**: быстрое и точное определение темпа (BPM), сетки ударов (Beatgrid) и времени первого сильного бита (Downbeat).
- 🔥 **Глубокий анализ от Первого Дропа (Drop-Anchored Grid — переключаемая PRO-функция)**:
  - При включении анализирует трек дольше и детальнее: находит **первый дроп** (мощный вход саб-баса и бочки после разгона/интро), уточняет эталонный BPM прямо на дропе и отсчитывает тактовую сетку назад к началу трека (`drop_time - N * bar_sec`).
  - Гарантирует, что сетка и точки каждые 8/16/32 бара попадут **ровно в первый удар дропа**, даже если у трека атмосферное интро без ударных или нестандартное вступление.
  - Отображает маркер `DROP` на форме волны и кликабельный бейдж тайминга первого дропа.
- 📥 **Импорт готовой сетки из Rekordbox XML**:
  - Загружайте экспортированный из Rekordbox `.xml` файл с уже проанализированной тактовой сеткой и BPM, чтобы мгновенно расставить только **Hot Cues** и **Memory Cues** строго по вашей сетке.
- ⚙️ **Настраиваемые интервалы**:
  - Каждые **8, 16, 32, 64 бара** или произвольное количество тактов.
  - Режимы точек: **Hot Cues** (кнопки A-H на пэдах с кастомными цветами), **Memory Cues** (точки памяти для обратного отсчета тактов на CDJ/XDJ) или **оба типа сразу**.
  - Шаблоны названий меток (`16 Bars`, `32 Bars` / `Bar 1`, `Bar 17`, `Bar 33` / `Intro, Drop, Break`).
- 🌊 **Интерактивная форма волны (Waveform)**:
  - Визуализация формы волны и расставленных точек с их цветами.
  - Встроенный плеер: кликните на любую точку или место на вейвформе, чтобы сразу послушать и проверить тайминг.
  - Точная подстройка сетки (+/- 10мс, +/- 50мс, изменение BPM в 2 клика).
- 📥 **Экспорт в Rekordbox XML**: создание стандартного файла `rekordbox.xml`, совместимого со всеми версиями Rekordbox 5 / 6 / 7.

## 🚀 Быстрый запуск

- **Основной способ**: дважды кликните по ярлыку **`CueGrid Pro.lnk`** в главной папке (запустит программу с официальной иконкой в отдельном окне без лишних черных консолей).
- **Альтернативный способ**: внутри папки `CueGridPro/` запустите `start.bat` (для консольного режима с логами) или `Launch_CueGridPro.vbs` (тихий запуск).

## 📖 Как импортировать результат в Rekordbox (за 2 клика)

1. В программе нажмите **«Экспорт в rekordbox.xml»** и сохраните файл.
2. Откройте **Rekordbox**:
   - Перейдите в **Настройки (Preferences / Шестеренка)** &rarr; вкладка **«Дополнительно» (Advanced)** &rarr; вкладка **«База данных» (Database)** &rarr; раздел **rekordbox xml**.
   - Нажмите **«Обзор» (Browse)** и выберите сохраненный файл `rekordbox_auto_cues.xml`.
3. В левой боковой панели Rekordbox раскройте пункт **rekordbox xml**:
   - Нажмите правой кнопкой мыши по созданному плейлисту **«Auto Cues»** (или по нужным трекам).
   - Выберите **«Импортировать в коллекцию» (Import to Collection)**.
4. **Готово!** Все Hot Cues и Memory Cues появятся на ваших треках с идеальной тактовой сеткой.
